# ברג ושות׳ — אתר משרד עורכי דין

## נקודות תצורה ב-index.html

| משתנה | תפקיד |
|--------|--------|
| `const DOCS` | מחירון נסחים (טאבו, חברה, מקרקעין וכו׳) |
| `const PAY_LINKS` | קישורי סליקה לכל סוג נסח. ערך ריק = fallback לוואטסאפ |
| `const PHONE` | מספר טלפון ראשי |
| מייל | michael@passparto.com |

## חוקים קדושים — אין לגעת!

1. **מבנה מפתחות i18n** — ארבעת מילוני השפה ומפתחותיהם
2. **גרש עברי** — U+05F3 ב"ושות׳" (ASCII apostroph שובר JS)
3. **מחירי היכרות** — 890 / 1090 / 1290 ₪
4. **דיסקליימר משפטי** — הטקסט בתחתית הדף

## מנגנון מאמרים יומי

`content/articles.json` — מערך מאמרים ב-4 שפות (he/en/ru/fr).
`renderArticles()` ב-index.html טוען את הJSON, ממיין לפי תאריך, ומציג 3 אחרונים
בכרטיסי המאמרים ובגזט. אם ה-fetch נכשל — ה-HTML הסטטי נשאר.
